# Troubleshooting

| What you see | What to try |
| --- | --- |
| The APK will not install | Check that you downloaded the APK from the release’s **Assets** section and allowed installs from the browser or file manager opening it. If a previous build is installed, see the upgrade notes in the release before uninstalling it. |
| QR code unavailable | Open **Initiate Chat**, enable Bluetooth and Wi-Fi, and check BackPost’s nearby permissions in Android settings. |
| Camera will not scan | Allow camera access, clean the lens, adjust the distance or screen brightness, or use **Find nearby**. |
| Nearby list is empty | Keep both phones close with BackPost open. Check Bluetooth, Wi-Fi, nearby permissions, and Google Play services on both phones. |
| A familiar name has a different fingerprint | Confirm the fingerprint in person before pairing. A reinstall or another phone can have a different identity. |
| A sent message is waiting | Reconnect to the verified device nearby. If you manually disconnected it, pair again. |
| A file is waiting for approval | Ask the receiving person to open that conversation and check the file request. |
| A completed file is missing from Downloads | Look in **Downloads/BackPost** and then check the conversation’s shared-files view for a private copy. |
| There is no notification | Check Android notification permission, BackPost’s settings, and whether the conversation is muted. A message has to arrive over a nearby connection before BackPost can alert you. |

When reporting a problem, include the BackPost version, both phone models and Android versions, and the steps that triggered the issue. Keep private messages, file names, live pairing QR codes, and full device fingerprints out of public reports.
