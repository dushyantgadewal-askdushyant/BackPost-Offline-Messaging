# Install BackPost and start a chat

## Install on both phones

1. On each Android phone, open the [BackPost download page](../README.md#download-for-android) and download the signed APK.
2. Open the downloaded APK. If Android asks you to allow installs from your browser or file manager, grant that permission to the app opening the APK, then return to the installer. You can turn the permission off after installation.
3. Open BackPost. Turn on Bluetooth and Wi-Fi and grant the nearby permissions Android requests. BackPost uses Google Play services for nearby connections.
4. Optionally allow notifications for incoming messages and transfer requests. Allow camera access if you want to scan a QR code.

## Pair with a QR code

1. Open **Initiate Chat** on both phones and wait for the live QR code.
2. On one phone, choose **Scan** and point its camera at the QR on the other phone.
3. Follow the prompts on both phones. When a pairing code appears, compare it on both screens before confirming.
4. Open the conversation and send a message. Once the device is paired, ordinary text messages arrive without a separate approval prompt.

The pairing QR is valid for up to 24 hours. If you saved an older QR and it expires, use the current code on the other phone.

## Pair without a camera

1. Keep both phones nearby with BackPost open and nearby access ready.
2. Choose **Find nearby**, then tap the other phone.
3. Compare the pairing code on both phones and confirm if it matches. If the device is already verified, tapping it opens its conversation when it reconnects.

BackPost uses the device fingerprint as its identity. You can compare fingerprints in person in the device information screens, especially if several phones use similar names.
